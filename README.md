# Northstar Bank — фронтенд

React + Vite интерфейс по ER-диаграмме банка. Включены все 10 таблиц: branches, employees, customers, accounts, account_holders, transactions, transfers, loans, loan_payments, bank_shareholders.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite (обычно http://localhost:5173). Для production-сборки: `npm run build`.

## Возможности

- Обзор с показателями, последними транзакциями и быстрыми переходами.
- Таблицы с поиском, сортировкой, фильтром статуса, страницами и CSV-экспортом.
- Добавление, изменение и удаление записей, выбор связанных сущностей в формах.
- Проверка связей перед удалением, уникальной пары счёт–клиент и общей доли владения.
- Демонстрационные данные сохраняются в `localStorage`; кнопка сброса в верхней панели.

Это автономный фронтенд без сервера. Он не проводит настоящие банковские операции: изменение записей сохраняется только в текущем браузере. Для работы с PostgreSQL подключите REST API и замените чтение/запись localStorage запросами к серверу; проверку прав доступа и бизнес-правила повторите на сервере. Тексты интерфейса — на русском; имена полей соответствуют диаграмме.
